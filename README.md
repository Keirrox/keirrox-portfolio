# KEIRROX — SaaS Motion Design Portfolio

A work-first editorial portfolio for an independent SaaS motion designer.

## Files
- `index.html` — page structure and project presentations
- `styles.css` — responsive design system and centralized theme tokens
- `script.js` — mobile navigation, contact configuration and reveal interactions
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment

## GitHub Pages
This repository is intended to publish as a project site. Enable **Settings → Pages → Build and deployment → Source: GitHub Actions** if it is not already enabled.

## Before sharing publicly
1. In `script.js`, replace `YOUR_EMAIL@example.com` with your real professional email.
2. Replace `YOUR_HANDLE` with your Instagram username (without @).
3. Replace the CSS project cover artwork in `index.html` with your final video previews/posters when ready.
4. Verify that you have permission to display every project and asset.

The current project artwork is original CSS-based cover artwork, not final project footage or proof of client work. Self-initiated work is identified as concept work.

## Theme
Edit the CSS custom properties at the top of `styles.css` to update the palette globally.
