# Keirrox portfolio — fresh build

A new art direction for an independent SaaS / product motion designer.

## Files
- `index.html` — page structure and project cover studies
- `styles.css` — responsive visual system and layout
- `script.js` — mobile navigation and contact links

## Publish on GitHub Pages
1. Open **Settings → Pages** in the repository.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.

## Personalise before publishing
Open `script.js` and replace:
- `YOUR_EMAIL@example.com` with your professional email.
- `YOUR_HANDLE` with your Instagram username (without @).

## Replace the project cover studies with your real videos
The three project visuals are art-directed cover studies, not embedded footage. Once your final MP4s are ready, replace each `.project-visual` anchor in `index.html` with a `<video>` element or a poster + play control. Keep the title, project type and year accurate. Do not publish any project you cannot show publicly.

## Design direction
Warm paper / near-black / signal red / acid-lime. Manrope for expressive, compact display typography and DM Mono for small labels. The layout is editorial and intentionally restrained: one large statement, three selected projects, a short capabilities section and direct contact.
